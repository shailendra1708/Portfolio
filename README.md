# My Portfolio

This started as a simple idea: **I wanted one place where I could put the things I've made, the things I'm learning, and the things I'm still figuring out.**

Instead of making it feel like a traditional resume, I wanted the portfolio to feel a little more like me — minimal, visual, and personal.

## A Little About This Project

I built this portfolio to bring different parts of my work together in one place.

Some projects are technical.
Some are creative.
Some are just experiments I wanted to try.

The idea is simple — **show the work, not just talk about it.**

You'll find projects I've worked on, services I can offer, video edits, photographs, and a little more about who I am outside of code.

## What You'll Find Here

### Projects

A collection of things I've built while learning, experimenting, and trying to turn ideas into something real.

### Video Edits

Video editing is one of the more creative parts of my work. This section is a collection of edits and moments I've put together frame by frame.

### Gallery

Some images I've collected or created along the way.

### About

Probably the most personal part of the website.

It's not just a list of skills. It's a little glimpse into the things I enjoy, the ideas that interest me, and the person behind the projects.

## Built With

* React
* Vite
* JavaScript
* Tailwind CSS
* HTML
* CSS

Nothing overly complicated. Just tools that helped me turn the idea into a working website.

## Running It Locally

If you want to explore the project yourself:

```bash
git clone https://github.com/shailendra1708/Portfolio.git
cd Portfolio
npm install
npm run dev
```

For a production build:

```bash
npm run build
```
